An entry for the [Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) bounty on make.fun.

`main.py` writes a single job title — 60 characters or fewer, nothing
else — to `/output/entry.txt`:

> Senior Counter of Ceiling Tiles Above Dentists' Chairs

A real-sounding senior role with one gloriously specific twist: the
ceiling tiles every patient stares at from the dentist's chair. The
program is deterministic — it writes the same bytes on every run.
